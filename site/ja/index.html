インストール

VS Code 拡張機能を入れて、セットアップを押すだけです。R・Python・Quarto・pandoc・Typst・フォントと octavo コマンドが、すべて自動で揃います。Linux・macOS・Windows ごとの手順もあります。

仕組み

できあがるもの

できること

数値は手入力しない

数値は分析結果から原稿に挿入します。分析を再実行すれば、すべての文書の数値がまとめて更新されます。

R でも Python でも

分析は Quarto の .qmd で、R でも Python でも書けます。環境の管理は Octavo が自動で行います。

1つの原稿から、必要な出力を

投稿先の書式に合わせた論文、授業資料、スライド、ポスター、Word を、1つの Markdown から出力できます。

図表・節をラベルで参照

図表の番号は自動で管理されます。順番を入れ替えても、番号は自動で更新されます。

投稿の前に点検する

ボタン1つで、本文に手入力された数値、仮の値、存在しない引用や図、字数・語数の上限超過を知らせます。

投稿から採択後まで

匿名審査用の版、投稿用の zip、再現用パッケージを作れます。

VS Code 拡張機能

原稿の横に、カーソルに合わせて動く PDF のライブプレビューを表示します。上の機能はサイドバーから操作でき、セットアップもボタン1つです。Linux・macOS・Windows に対応し、表示は英語と日本語です。

AI アシスタントと使える

プロジェクトごとの約束事（結果を原稿に手入力しない、など）を AGENTS.md に置きます。Claude Code・GitHub Copilot・Codex・Antigravity はどれもこれを読むので、AI アシスタントは最初からその約束を知っています。アシスタントが調べるリファレンスも Octavo に同梱しています。
