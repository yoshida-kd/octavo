Octavo

計量社会科学スターターパック

論文・スライド・講義ノートは Markdown で書き、分析は Quarto で行う。分析が出した数値・図・表は Octavo がどの文書にも差し込み、PDF（Typst）と Word に仕上げる（TeX があれば LaTeX にも）。文献は1つの .bib から、好きな CSL スタイルで整形される。

数値を手で書かない

分析で登録し（ov_value("n_obs", nrow(d))）、原稿では名前で呼ぶ（{{n_obs}}）。分析を再実行すれば、すべての文書の数値がまとめて更新される。

R でも Python でも

分析は Quarto の .qmd で、R でも Python でも書ける。どちらにも同じ補助関数があり、プロジェクトの .venv と renv も用意される。

1つの原稿から、いくつもの文書

投稿先の書式に合わせた論文、発表スライド、A4 のプリントと回ごとのスライドを兼ねる講義ノート。発表者用の台本も、共著者に回す Word も出せる。

ラベルで参照する

@fig-trend は「図2.1」になり、節を並べ替えても、番号は正しいまま。

投稿の前に点検する

octavo check が、本文に手入力された数値、仮の値、存在しない引用や図、規定の分量オーバーを知らせる。

投稿から採択後まで

匿名審査用の出力、投稿用の zip、共著者が Word で入れた変更履歴の読み取り、投稿後に変わった数値の一覧、再現用パッケージ。

VS Code 拡張

原稿の横に、カーソルに合わせて動く PDF のライブプレビュー、上の機能を操作できるサイドバー、ボタン1つのセットアップ。Linux・macOS・Windows に対応し、表示は英語と日本語。

AI アシスタントと使える

プロジェクトごとの約束事を AGENTS.md に置く。Claude Code・GitHub Copilot・Codex・Antigravity のどれもが読む。

TikZ なしで図を描く

箱と矢印の図、因果グラフ、フローチャートは、専用のファイルに Typst で描く。octavo new figure dag が小さな diagram()（パッケージは使わない）入りの figures/dag.typ を置き、octavo build が通常の図として組み込む。どの出力形式でも使え、番号が付き、ラベルで参照できる。

#diagram(
  (z: (2, 0, [Background $Z$]),
   x: (0, 1.6, [Education $X$]),
   y: (4, 1.6, [Income $Y$]),
   u: (4, 3, [Unobserved $U$], (stroke: none))),
  (("z", "x"), ("z", "y"), ("x", "y"),
   ("u", "y", (dash: "dashed"))),
)

手引きで詳しく

インストール

VS Code なら、Octavo 拡張 をインストールし、案内が出たら「セットアップ」を押す。pandoc・Typst・Quarto・R・フォントと octavo コマンドがまとめて入る。

ターミナルなら:

curl -LsSf https://astral.sh/uv/install.sh | sh
uv tool install octavo-kit
octavo setup     # pandoc / Typst / Quarto / フォント / R
octavo doctor    # 足りないものを報告する

Linux・macOS・Windows ごとの手順は手引きにある。

始め方

まずは見本で動作を確かめる（分析・論文・スライド・講義ノート）:

octavo init demo --all --example
cd demo
octavo build --compile

自分のプロジェクトは、必要な部品だけで始める:

octavo init study --with analysis,paper
cd study
octavo env       # 分析の環境（.venv と renv）
octavo build paper --compile
octavo check     # 投稿する前に

手引き

使い方はすべて手引きにある。講義ノートは講義ノートの作り方に1ページでまとめてある（VS Code で作る手順と、記法の早見表）。

  1. インストール — Linux・macOS・Windows を順に
  2. 最初のプロジェクト — octavo init と octavo new、分析の環境
  3. 原稿を書く — 参照、番号の付くブロック、数式、図、表
  4. 分析 — Quarto から数値・図・表を
  5. 文献
  6. 論文 — 点検、匿名審査、投稿、改訂
  7. スライドと講義ノート — 回の区切り、回ごとの配布資料
  8. 自分用にする — テンプレート、Word のスタイル、書体
  9. コマンド一覧
  10. VS Code
  11. 自分の機械で確かめること
