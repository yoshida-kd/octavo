Octavo

The quantitative social science starter pack

From analysis to writing.

Get the VS Code extension Quick guide

Install

Install the VS Code extension and press Set up. That's all: R, Python, Quarto, pandoc, Typst, the fonts and the octavo command are installed for you.

How it works

What you get

What it does

No number typed by hand

Numbers are inserted into the manuscript from the analysis results. Re-run the analysis, and every document updates at once.

R or Python

Write the analysis as a Quarto .qmd in R or Python. Octavo sets up and manages the environment for you.

One manuscript, the outputs you choose

Get a paper in your journal's layout, course materials, slides, a poster and a Word file, all from one Markdown file.

References by label

Figure and table numbers are managed for you. Reorder things, and the numbers update automatically.

Checked before you submit

octavo check finds numbers typed into the prose, placeholder values, missing citations and figures, and manuscripts over a word limit.

Submission and beyond

Make a blind-review version, a submission zip and a replication package.

A VS Code extension

See a live PDF beside the manuscript that follows your cursor, run everything above from a sidebar, and set up with one click. It works on Linux, macOS and Windows, in English and Japanese.

Ready for your AI assistant

Every project keeps its working rules (such as never typing a result into the manuscript) in AGENTS.md. Claude Code, GitHub Copilot, Codex and Antigravity all read it, so the assistant knows the rules from the start.
