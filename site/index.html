Octavo

The quantitative social science starter pack

Write your papers, slides and lecture notes in Markdown, keep the analysis in Quarto, and let Octavo place the analysis's numbers, figures and tables in every document — then typeset them to PDF (with Typst) and Word, or LaTeX if you have TeX. Citations come from one .bib file, in any CSL style.

How it works

What you get

What it does

No number typed by hand

The analysis registers a value (ov_value("n_obs", nrow(d))) and the manuscript calls it by name ({{n_obs}}). Re-run the analysis and every document follows.

R or Python

The analysis is a Quarto .qmd in R or in Python, with the same helpers in both, and the project's .venv and renv set up for you.

One source, several documents

A paper in your journal's layout, a talk, and lecture notes that become an A4 handout plus one deck per session — with speaker scripts, and Word for coauthors.

References by label

@fig-trend becomes “Figure 2.1”, and stays right when you reorder sections.

Checked before you submit

octavo check finds numbers typed into the prose, placeholder values, missing citations and figures, and word limits exceeded.

Submission and beyond

Blind review, a submission zip, a coauthor's tracked changes in Word, what moved since you submitted, and a replication package.

A VS Code extension

A live PDF preview beside the manuscript that follows the cursor, a sidebar for all of the above, and one-click setup. Linux, macOS and Windows; English and Japanese.

Ready for your AI assistant

Every project keeps its working rules in AGENTS.md, which Claude Code, GitHub Copilot, Codex and Antigravity all read.

Diagrams without TikZ

Boxes and arrows, a causal graph, a flow: draw it in Typst, in a file of its own. octavo new figure dag writes figures/dag.typ with a small diagram() helper (no packages), and octavo build turns it into a figure like any other — in every format, numbered, and referred to by label.

#diagram(
  (z: (2, 0, [Background $Z$]),
   x: (0, 1.6, [Education $X$]),
   y: (4, 1.6, [Income $Y$]),
   u: (4, 3, [Unobserved $U$], (stroke: none))),
  (("z", "x"), ("z", "y"), ("x", "y"),
   ("u", "y", (dash: "dashed"))),
)

Install

With VS Code, install the Octavo extension and press Set up when it asks: it installs pandoc, Typst, Quarto, R, the fonts and the octavo command.

From a terminal:

curl -LsSf https://astral.sh/uv/install.sh | sh
uv tool install octavo-kit
octavo setup     # pandoc / Typst / Quarto / fonts / R
octavo doctor    # reports anything still missing

Step by step for Linux, macOS and Windows in the guide.

Getting started

Try the example first — an analysis, a paper, slides and lecture notes:

octavo init demo --all --example
cd demo
octavo build --compile

Then your own project, with just the parts you need:

octavo init study --with analysis,paper
cd study
octavo env       # the analysis environment (.venv and renv)
octavo build paper --compile
octavo check     # before you submit
