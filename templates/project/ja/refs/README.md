# 参考資料

**外から来た資料**の置き場。自分で書いたメモは `notes/` のほう。

- コードブック・調査票・データの利用条件
- 投稿規定・執筆要領・スタイルガイド
- 一次資料（報告書、議事録など）

`octavo build` はここを見ない。原稿から参照するものではなく、**作業中に
自分が読むもの**を置く。

## 決まりごと

- **git に入れる。**共著者と共有し、半年後の自分が同じ資料を見られるように。
  入れて困るもの（再配布できない PDF、大きいファイル）は `.gitignore` に
  その分だけ足す
- **論文の PDF はここに置かない。**書誌と本文 PDF は Zotero が正本で、
  二重に持つと版がずれる。ここに置くのは Zotero に入らない種類のもの
- 何をなぜ置いたかが分かるように、ファイル名か、この README に1行足す

| ファイル | 何か | 出所 | 取得日 |
|---|---|---|---|
| （例）codebook_example.pdf | （例）調査のコードブック | （例）配布元のサイト | 2026-01-15 |
