# Notes

A place for **things you wrote**. None of it goes into a manuscript
(`octavo build` never looks here). Material that came from elsewhere
(codebooks, questionnaires, submission guidelines) goes in `refs/`.

Make whatever you need. Common ones:

- `reading/` … reading notes. Writing `@key` makes them easy to move into a manuscript later
- `referee/` … referee comments and how you answered them
- `todo.md` … what is left

The bibliography itself lives in Zotero. Here you write what you thought of it.
