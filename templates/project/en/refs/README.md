# Reference material

A place for **material that came from elsewhere**. Notes you wrote yourself
go in `notes/`.

- codebooks, questionnaires, terms of use for data
- submission guidelines, style guides
- primary documents (reports, minutes)

`octavo build` never looks here. This is not something the manuscripts
refer to, but **what you read while working**.

## Conventions

- **Keep it in git**, so coauthors share it and your future self sees the same
  files. Add anything that must not be committed (PDFs you may not
  redistribute, very large files) to `.gitignore` one by one
- **Don't put papers here.** Zotero holds the bibliography and the PDFs;
  keeping a second copy lets the two drift. This folder is for what Zotero
  doesn't hold
- Make it clear what each file is and why it's here, in its name or with a line
  in this README
