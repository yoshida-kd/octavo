# Raw data

**Never modify what is in this folder.** Clean the data in `analysis/*.qmd`
and write the result to `data/derived/`. Editing raw data by hand makes it
impossible to trace what changed where.

`data/raw/` is in `.gitignore` and stays out of git (so large or
non-redistributable files can't be committed by accident). **That makes this
README the only record that survives.** Add a line whenever you add data.
