# 原データ

**このディレクトリの中身は書き換えない。**整形は `analysis/*.qmd` で行い、
結果は `data/derived/` に書くこと。原データを直接直すと、どこで何が変わったかが
追えなくなる。

`data/raw/` は `.gitignore` で git に入らない（大きいファイルや再配布できない
データを事故で commit しないため）。**したがって、この README だけが記録に残る。**
データを置いたら必ず1行足すこと。

|---|---|---|---|

## 手で写し取ったデータ

官公庁の PDF や図から数字を拾って作ったデータもここに置き、上の表に「出所: 〇〇から手入力」
と書く。写し終えたら取得したデータと同じく書き換えない。誤りを直したら、何をどう直したかを
ここに書く。手で作ったものは取り直せないので、再配布に問題がなければ `.gitignore` に
`!data/raw/<ファイル>.csv` を足して git に入れる。
